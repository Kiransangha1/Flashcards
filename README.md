# Flashcards Web Application

## Overview
The Flashcards Web Application is a full-stack web application designed to help users create, organize, and review flashcards in a structured and user-friendly way. The project addresses a common learning challenge: managing study material efficiently while keeping information organized and easily accessible.

By allowing users to group flashcards into folders and interact with them through a clean web interface, this application supports effective studying, memorization, and long-term learning.
